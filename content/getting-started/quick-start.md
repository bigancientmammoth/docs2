# Быстрый старт

Создай своего первого агента за 5 минут.

## Шаг 1. Создай агента

1. Открой раздел **Агенты** в левом меню
2. Нажми **+ Новый агент**
3. Введи название, например `Агент поддержки`

## Шаг 2. Настрой модель

1. В разделе **Модель** выбери провайдера (OpenAI, Anthropic и др.)
2. Укажи модель, например `gpt-4o`
3. Введи системный промпт — это инструкция для агента

Пример системного промпта:
```
Ты — помощник службы поддержки компании Robocom.
Отвечай вежливо и по делу. Если не знаешь ответа — 
предложи связаться с командой поддержки.
```

## Шаг 3. Добавь триггер

1. Перейди на вкладку **Ноды**
2. Добавь ноду **Telegram** или **Веб-чат**
3. Следуй инструкции для подключения

## Шаг 4. Протестируй

Используй встроенный **Playground** — он доступен в правом верхнем углу редактора. Можно общаться с агентом до деплоя.

## Шаг 5. Задеплой

Нажми кнопку **Опубликовать** — агент становится активным мгновенно.
