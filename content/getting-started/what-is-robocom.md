# Что такое Robocom

Robocom — это low-code платформа для создания ИИ-агентов. Вместо написания кода ты собираешь логику агента из готовых блоков (нод) в визуальном редакторе.

## Для кого

- **Продуктовые команды** — автоматизация поддержки, онбординга, внутренних процессов
- **Маркетологи** — персонализированные диалоги, квалификация лидов
- **Разработчики** — быстрый прототип без boilerplate

## Как это работает

1. Создаёшь агента и выбираешь ИИ-модель (GPT-4, Claude и др.)
2. Настраиваешь поведение через системный промпт и ноды
3. Подключаешь триггер (Telegram, webhook, чат на сайте)
4. Деплоишь одной кнопкой

## Ключевые возможности

- Визуальный редактор без кода
- Поддержка ведущих ИИ-моделей
- Встроенная память агента
- Более 20 готовых интеграций
- Аналитика и логи в реальном времени
